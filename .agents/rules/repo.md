# Repository Conventions

## Language and Formatting
- Every file in the repo stays in English.
- Use clean Markdown and Mermaid diagrams.
- Use kebab-case for file and folder names.
- Package manager: `pnpm`.

## Project Structure
- `/src`: Fastify backend application source code.
- `/docker`: Modular Docker service definitions.
- `/scripts`: Operational scripts and database seeders.
- `/docs`: Theoretical concepts and architecture principles.
- `/case-studies`: Real-world architectural breakdowns.
- `/.agents`: Central source of truth for all AI agent instructions.
